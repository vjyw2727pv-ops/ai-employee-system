# AI Employee System

نظام موظفين ذكاء اصطناعي مكون من:

- مدير
- موظف مبرمج 1
- موظف مبرمج 2
- مصحح أخطاء

## الوصف

هذا المشروع يمثل نموذجًا مبسطًا لنظام إدارة فريق برمجي قائم على وكلاء ذكاء اصطناعي، حيث يقوم المدير بتوزيع المهام، ويقوم المبرمجون بتطوير الوحدات، ويقوم مصحح الأخطاء بمراجعة وحل المشاكل.
