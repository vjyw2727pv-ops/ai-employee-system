# AI Employee System

نظام موظفين AI محول إلى تطبيق ويب باستخدام Flask.

## التشغيل

1. تثبيت المتطلبات:

```bash
pip install -r requirements.txt
```

2. تشغيل التطبيق:

```bash
python app.py
```

3. افتح المتصفح على:

```text
http://localhost:5000
```

## مكونات التطبيق

- مدير المشروع
- موظفان مبرمجان
- مصحح أخطاء
- لوحة تحكم تفاعلية تعرض المهام والإنجازات
