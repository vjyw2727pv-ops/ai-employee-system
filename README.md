# AI Employee System

نظام كامل لإدارة فريق ذكاء اصطناعي يتكون من:

- مدير المشروع
- موظفان مبرمجان
- مصحح أخطاء

## الوصف

هذا المشروع يمثل نسخة كاملة ومباشرة من نظام داخلي لإدارة فريق تطوير باستخدام وكيل/موظف AI. يقوم المدير بتوزيع المهام، ويقوم المبرمجان بإنجاز الوحدات المختلفة، ثم يأتي مصحح الأخطاء لتحليل المشكلات وإصلاحها قبل التسليم النهائي.

## مميزات النظام

- إنشاء المهام وإدارتها
- تعيين المهام إلى الموظفين المناسبين
- متابعة حالة كل مهمة
- تطوير ميزات واجهة ومجتمع منطق
- تحليل المشكلات البرمجية
- إصلاح الأخطاء وتوثيق النتيجة
- حفظ المهام في ملف JSON
- تشغيل كواجهة سطر أوامر (CLI)

## مثال الإخراج

```text
=== نظام موظفين AI ===
📋 المدير: تم إنشاء المهمة 'واجهة تسجيل الدخول'
📌 المدير: تم تعيين المهمة إلى المبرمج 1
💻 المبرمج 1: تم بناء الميزة 'واجهة تسجيل الدخول'
🔍 المبرمج 1: تم مراجعة الكود الخاص بـ 'واجهة تسجيل الدخول'
📋 المدير: تم إنشاء المهمة 'نظام المصادقة'
📌 المدير: تم تعيين المهمة إلى المبرمج 2
🛠️ المبرمج 2: تم بناء الوحدة 'نظام المصادقة'
✅ المبرمج 2: تم اختبار الوحدة 'نظام المصادقة' بنجاح
🔎 مصحح الأخطاء: تم تحليل المشكلة 'فشل في التحقق من البيانات'
🛠️ مصحح الأخطاء: تم إصلاح المشكلة 'فشل في التحقق من البيانات'
✅ تم إنجاز جميع المهام الأساسية للنظام
```

## ملاحظات

هذا المشروع مصمم ليكون قاعدة قوية للتوسع لاحقاً إلى:

- API باستخدام FastAPI
- تطبيق ويب باستخدام Flask أو Django
- نظام قاعدة بيانات SQLite
- لوحة تحكم للمشاريع
- نظام ذكاء اصطناعي متقدم مع OpenAI أو Azure OpenAI
